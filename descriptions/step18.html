El procesamiento de la evidencia. Aquí defines las herramientas estadísticas o lógicas que usarás para organizar, resumir e interpretar la información obtenida.

  • Análisis Descriptivo: Uso de frecuencias, porcentajes, medias y desviaciones típicas para retratar tu muestra (común en estudios cuantitativos).
  • Análisis Inferencial: Aplicación de pruebas (ej. T de Student, Correlación de Pearson) para probar tus hipótesis y generalizar resultados.
  • Análisis de Contenido: Codificación y categorización de discursos o textos para extraer temas recurrentes (común en estudios cualitativos).
  • Software de Apoyo: Especifica si usarás herramientas como SPSS, Excel, Atlas.ti o R para el procesamiento de datos.

Tip: El plan de análisis debe ser "espejo" de tus objetivos; si tienes tres objetivos específicos, debes tener al menos tres procedimientos de análisis.
